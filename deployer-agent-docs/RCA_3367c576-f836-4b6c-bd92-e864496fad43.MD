## Root cause
The frontend build (`frontend-build` stage, `yarn build`) failed to compile. The CRA/ESLint
compiler emitted a hard syntax error:

```
src/pages/LiveTV.jsx
Syntax error: Identifier 'isLive' has already been declared. (1288:10)
error Command failed with exit code 1.
```

This is NOT a manifest / infra / env problem. It is a duplicate `const` declaration in the
shipped source. Item #5 of the change set ("Fixed a build error from a duplicate `const isLive`
declaration") was intended to resolve exactly this, but the fix is **not present in the source
that was pulled for this run** — the duplicate is still there.

## Evidence (confirmed in the eph sandbox against this run's pulled source)
`grep -n 'const isLive' frontend/src/pages/LiveTV.jsx`:
```
1244:    const isLive = currentVideo.is_live === true;
1288:    const isLive = currentVideo.is_live === true;
```

Both declarations live inside the **same function body** (the YouTube-player effect). The flow is:
- line 1244 — `const isLive` declared just before the FAST PATH (`loadVideoById`) block.
- the fast path is an `if (...) { ... return; }` block — it does NOT open a new function scope.
- line 1288 — `const isLive` declared AGAIN at the top of the SLOW PATH, in the same scope → redeclaration → compile error.

Line 1244's `isLive` is already in scope for the whole function, including every slow-path use
(1292, 1334, 1339, 1349, 1361, 1409, 1426, 1437, 1465, 1475), so the second declaration is pure
duplication.
